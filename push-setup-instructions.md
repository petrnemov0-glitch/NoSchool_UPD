# Push-уведомления на устройство — развёртывание (ручной шаг)

Клиентская часть (запрос разрешения, подписка, показ уведомления) уже в
приложении и работает сразу после загрузки файлов. Но чтобы уведомления
реально ДОХОДИЛИ до устройства, нужна серверная часть — а её нельзя
"залить" простой загрузкой файлов, как остальной сайт. Это отдельная
настройка в панели Supabase, один раз.

## Шаг 1 — выполните SQL
`supabase-migration-push.sql` в SQL Editor (как обычно).

## Шаг 2 — создайте Edge Function
1. В Supabase откройте **Edge Functions** в левом меню.
2. **Create a new function**, назовите `send-push`.
3. Откройте файл **`supabase-push-function.ts`** из этого архива, скопируйте всё содержимое.
4. Вставьте в редактор функции на месте заглушки → **Deploy**.

## Шаг 3 — добавьте секреты функции
Там же, в настройках функции (или **Edge Functions → Secrets**), добавьте:

| Имя | Значение |
|---|---|
| `VAPID_PUBLIC_KEY` | `BGobfLG7d2oRaA44A_P02FT_mh9eR1T1EfKZJZgFFR2NWCQURHnRIRu0jANE3iCk4Nh6RAXmYdv8LHhFVoXVhN0` |
| `VAPID_PRIVATE_KEY` | `LhgrAyFYwZX428UPXii9vrapSgPAIr8zxRivKvlxZS4` |
| `SUPABASE_URL` | ваш Project URL (тот же, что в `config.js`) |
| `SUPABASE_SERVICE_ROLE_KEY` | Project Settings → API → **service_role key** (секретный, не публикуемый) |

⚠️ `VAPID_PRIVATE_KEY` и `SUPABASE_SERVICE_ROLE_KEY` — секретные значения.
Никогда не вставляйте их в `config.js` или куда-либо в код фронтенда —
только в секреты Edge Function, как здесь.

## Шаг 4 — подключите Database Webhook
1. **Database → Webhooks → Create a new webhook**.
2. Table: `notifications`, Events: **Insert**.
3. Type: **HTTP Request**, метод **POST**, URL — адрес вашей функции (Supabase покажет его на странице функции `send-push`, обычно вида `https://<project>.supabase.co/functions/v1/send-push`).
4. Headers: добавьте `Authorization: Bearer <anon key>` (тот же, что в `config.js`).
5. Сохраните.

Теперь при каждой вставке новой строки в `notifications` (то есть при
каждом реальном событии — новый запрос на перенос, решение по нему)
Supabase сам вызовет функцию, а она отправит push на все подписанные
устройства этого пользователя.

## Шаг 5 — проверка на реальном устройстве
1. Загрузите обновлённые файлы на сайт, откройте на телефоне.
2. Профиль → Настройки → **«🔔 Включить уведомления на устройство»** → разрешите в браузере.
3. Вызовите любое событие (например, попросите родителя запросить перенос) → должно прийти системное уведомление, даже если вкладка закрыта.

## Известные ограничения
- iPhone: push-уведомления в PWA работают только начиная с iOS 16.4+, и только если сайт добавлен на экран «Домой» (открыт как отдельное приложение, не как вкладка Safari).
- Регулярные напоминания «занятие через 30 минут» / «пора оплатить» этим не покрываются — они требуют ещё и планировщика (например, `pg_cron` + периодический вызов той же функции), это можно добавить отдельным шагом позже.
